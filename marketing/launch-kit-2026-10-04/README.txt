DaBin marketing launch kit — prepared 4 October 2026

Extract the ZIP, then open START_HERE.html. It previews the video and links the
PDF guide, calendar, copy, graphics, editable sources and local landing page.

Included:
01_Launch_Playbook — PDF guide, strategy, first-month calendar, checklist,
  ten verified creator/publication targets, source links and blank trackers.
02_Copy — editable text drafts for social, Reddit, Product Hunt, creator pitches,
  press, App Store, Apple featuring, landing page, demo briefs and replies.
03_Graphics — landscape/square/vertical graphics, three benefit cards, robot/icon.
04_Video — 22-second landscape and portrait MP4s, silent versions, SRT and voice.
05_Landing_Page — self-contained editable static HTML preview with public media.
06_Source — packed Blender files, scripts, native UI fixtures and voice takes.
07_QA — visual contact sheets, full decode results, technical/provenance checks.

Launch-specific fields are deliberately not invented:
[[APP_STORE_URL]], [[WEBSITE_URL]], [[CONTACT_EMAIL]], [[RELEASE_DATE]], and
personalization placeholders. Set actual values only after the release is live.
Landing page config.js has empty App Store/contact fields, so its download
buttons remain disabled until a genuine apps.apple.com link is configured.

Free means the currently requested free product. This kit does not promise a
permanent future pricing policy, cloud sync, semantic AI search or a whole-Mac
search. Optional website previews can contact manually saved websites.

The Feed DaBin film is an editorial animation made with local Blender, using
the exact current native robot and actual interface states from isolated
fictional captures. It is not a continuous screen recording. Narration uses
the user-authorized ElevenLabs service. No KARI intellectual property or real
personal captures were submitted to external generation services.

No outreach, social posting, featuring nomination, App Store submission or
website deployment occurred. Before posting, compare UI and claims with the
published app and fill the selected copy's clearly marked fields.

Do not upload the entire kit as a public website. Only copy the specified
05_Landing_Page public files into a deployment folder when publishing.

The SHA256 manifest inventories delivered files. The ZIP was CRC-tested.
Intermediate render frames, logs, build binaries and Blender backups are
excluded. Artwork originals and app source were preserved.
