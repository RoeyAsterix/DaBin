# DaBin 0.4.43 (98) — hide the robot while paused

Auto Capture previously retained a project sign while paused, and hover, saved-item feedback or a task-timer alarm could still reveal robot artwork. Paused now hides every companion robot and sign immediately while keeping the expanded board and status controls usable.

- Paused overrides corner/camera placement, hover and drop reveals, queued or late confirmation feedback, manual saves, Quiet mode, Reduce Motion and restart. The emitted pause value reaches the corner controller before presenter callbacks, preventing a synchronous stale-state reveal.
- The expanded board retains its content and window controls without decorative face/limbs. Focus robot opens the plain board while paused; the menu bar still reports Paused.
- Running timers and unacknowledged alarm/reminder state are preserved. Pausing only suppresses robot presentation; surviving alarms can present after Resume. Saved captures and the selected project are retained.

## Retained interface and local-data changes

- Projects, Tasks and Captions remain the three main tabs. The upper **+** opens New task directly. Task priority uses green-to-red color tags on the card, and the Tasks icons share one line without repeated headings.
- Captions puts Day, Week and type filters on one line, removes Paste/Add items buttons and labels, and shows **An Idea/Task for <project>** in its text input. Week omits days without captions. [Caption toolbar](qa/captions-toolbar-2026-10-05/verification.json), [populated weeks](qa/weekly-populated-days-2026-10-05/verification.json).
- Projects puts filters, dates, list/grid and **Export Selected** on one row. Items are newest first; My order and the standalone Note editor button are removed. Project notes are preserved. Its compact calendar selects a day or complete locale calendar week immediately, with month navigation, activity dots and Any date/Today/This week shortcuts. Select items to export one ZIP with original files, notes and task details. [Calendar verification](qa/project-date-picker-2026-10-05/verification.json), [project toolbar](qa/project-toolbar-2026-10-05/verification.json), [selected-export evidence](qa/export-selected-2026-10-05/verification.json).
- Search starts across saved DaBin content, accepts typing and keyboard paste, and organizes results by date. Captions/cards offer native outgoing text, link and verified saved-file drag payloads; the receiving application chooses its supported formats. Local archive/project folder actions reveal Finder locations, and the header grip moves the window across displays. [Search input](qa/full-qa-2026-10-04/README.md), [outgoing-drag verification](qa/outgoing-drag-verification-2026-10-04/README.md).
