# DaBin 0.4.17 (72) - preview-led Explorer capture cards

Explorer cards now give visual captures a large, full-width preview instead of a 56-point square. The preview grows with the card width, using a bounded 160–300-point surface. The complete image or document page fits inside it without cropping. Title, original capture date/time and category sit underneath; the project remains first, with copy and recoverable removal kept outside the selection target. Content-trail and task actions use a compact footer that wraps at narrow widths.

Images, video stills, PDF/document pages and other captures with a saved thumbnail receive the large treatment. Promoting an image to a task no longer hides its preview. Text-only notes and generic files without a thumbnail remain compact. Child attachments keep their inherited project and attachment badge. Browsing still selects the inspector in a wide window and opens capture details in a compact window; keyboard navigation, Return, context actions and drag payloads retain their established behavior.

Cards reuse existing local thumbnails through the serial, bounded background cache. There is no per-row full original decode, PDF/video player, website lookup or task-attachment scan. The change does not alter capture contents, task state or archive membership.
