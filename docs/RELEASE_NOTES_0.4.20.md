# DaBin 0.4.20 (75): find saved text by project and date

Search is now explicit about where and when it looks. Choose a named project, Unfiled or All projects, then All dates, One day, One week or an inclusive custom Date range. Week means seven calendar days ending on the chosen date. Date changes retain the query, project, source app and type filters.

The search icon and Command-K retain the current project and Day/Week context. **Search everything** keeps the query but deliberately clears project, dates, app and type. Returning from a result retains search refinements; Back restores the originating work. Task attachments follow their live parent task's project, including when moved or unfiled. Nearby context cannot cross the selected project, date or app boundaries; different-type neighbors remain labeled context and do not inflate the match count.

## Document text stays local

Word `.docx` main-body paragraphs and tables join PDF text, scanned-page/image OCR, plain text, Markdown, RTF and the existing structured text/source formats. Matching indexed lines appear on result cards. Case/diacritic folding and multiword search also consider titles, filenames, comments and project metadata.

DOCX parsing uses a bounded in-memory ZIP/XML reader and macOS zlib. It never unpacks members to disk, follows relationships, retrieves external entities or contacts a converter/service. Existing DOCX indexes are updated once without unnecessarily re-recognizing unchanged images and PDFs. Older completed v1 indexes remain valid on archive reopening and backup restore; invalid or future index versions still fail safely. Extraction uses only DaBin-managed saved copies; original source files and capture dates are unchanged.

Limits remain explicit: 100 PDF pages, 300,000 extracted characters and 12 MiB text/RTF/DOCX input. DOCX expanded package bytes and XML complexity are bounded. Encrypted, malformed or unusual packages fail clearly. DOCX headers, footnotes, comments and embedded-image OCR are not covered; legacy `.doc`, Pages and other Office internal text remain unsupported. This searches saved DaBin content, not every Mac file; results do not jump to an exact PDF page or highlight within an external document. Scratchpads show their edited date, which determines date membership.
