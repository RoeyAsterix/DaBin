# What comes after the foundation

The review prioritizes fewer steps from captured material to completed work. Optional tools belong in a task or selected-item context, not another top-level navigation destination.

| Priority | Capability | Practical benefit | Cost and complexity | Decision |
|---|---|---|---|---|
| Now | Local OCR/PDF text | Find and reuse screenshot/document text | Already implemented with native Vision/PDFKit | Retain, include in search and regression QA |
| Next | Task-linked focus timer | Start a short work session without another tool | Moderate: persistent pause/finish, sleep/wake accounting, accessible feedback | Defer until Today planning is tested in real working days |
| Next | Editable time records + CSV | Freelancers can review billable work | Moderate: timer correction, project attribution, rounding and export clarity | Pair with focus sessions; do not infer billable time from captures |
| Next | Quiet schedules | Avoid buddy animation outside working hours | Small for animation; larger for notification deferral and time zones | Existing explicit Quiet mode and macOS Focus remain available; add schedules with clear reminder semantics |
| Later | Calendar timeboxing | Reserve time for planned tasks | High: permission denial, event IDs, duplicate prevention, two-way edits, offline sync | Defer until a single-calendar provider and ownership rules are chosen |
| Later | Live external folder/file references | Avoid copying very large collections | High: security-scoped bookmarks, moved volumes, broken refs and permissions | Current managed copies preserve access and source provenance; no destructive original operations |
| Later | Batch rename / image resize / text cleanup | Useful selected-item utilities | Moderate, with explicit preview and undo | Add only to selection actions after demand is demonstrated |
| Later | File organization recipes | Repeated filing steps | High: dry-run, collision handling, reversible cross-volume moves | Do not automate filesystem mutation before a preview/recovery design exists |
| Later | Sequential paste / text expansion | Faster repetitive replies | High: global keystrokes and Accessibility permissions | Named snippets + explicit plain-text copying cover the basic use case with less interruption |
| Later | Optional AI for selected content | Suggest next steps and summarize long notes | High: consent, provider/account, cost, external content handling | No automatic external processing added; core remains local |

## Feedback to collect in a pilot

Observe several freelancers doing real capture, project switching, daily planning, and retrieval over a week. Measure time-to-next-action, unsuccessful searches, overlooked Inbox items, unwanted interruptions, and whether the shelf/clipboard distinction is understood. The screenshots and interaction counts in this review are expert evaluation, not user-study evidence.
