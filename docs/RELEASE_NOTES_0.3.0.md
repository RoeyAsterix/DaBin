# DaBin 0.3.0

DaBin can now check its public GitHub Releases channel from inside the app. Open **Settings → Software updates**, choose **Check for updates**, then use **Download & install** when a newer release is available.

The check runs only when requested. Downloads are restricted to the DaBin repository and verified by exact size and SHA-256 before the installer opens. The installer confirms the change, re-verifies the app, keeps a backup of the previous installation and preserves the local capture archive.

This release also adds dark mode, adjustable board transparency, and one shared caption card for files pasted or dropped together. The quick guide and privacy policy have been updated.
