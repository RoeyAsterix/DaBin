# DaBin 0.3.10

## Find copied and pasted text quickly

- Daily now has a dedicated **Text** filter immediately to the left of Links.
- Its purple aligned-text icon follows the same size, spacing, hover, pressed, focus and selected treatment as the existing filters.
- Hovering the icon shows **Copy/paste text**, and assistive technology receives the same clear name.
- Text includes plain text captured by copy, paste or drag. Links, tasks and document files stay in their own filters.

## Consistent throughout DaBin

- The filter works in Daily, contextual Search, Weekly and automatic hourly summaries.
- Search still shows one neighboring action before and after a matching text result for context.
- Weekly keeps dates with any recorded activity visible while filtering the cards inside those dates.
- The six centered filter controls fit the existing 380-point Daily board without widening or wrapping it.

## Data compatibility

The update changes only filtering and presentation. Existing captures, cards, tasks, comments, reminders and archive folders require no migration.
