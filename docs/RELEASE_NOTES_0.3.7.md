# DaBin 0.3.7

DaBin 0.3.7 makes the compact header clearer and more consistent.

## Settings wheel

The three-dot options icon in Daily and Weekly is now an outline settings wheel. It uses the same size, muted colour and click area as the task, search and reminder icons beside it.

The wheel opens the same menu as before, including Auto Capture pause or resume when available and **Settings…**. Its help and VoiceOver label now read **Settings and options**.

## Update

From DaBin 0.3.6, open **Settings → Software updates**, choose **Check for updates**, then **Download & install**. DaBin verifies the release size and SHA-256 checksum before its installer asks to replace the app. Your capture archive stays in place.
