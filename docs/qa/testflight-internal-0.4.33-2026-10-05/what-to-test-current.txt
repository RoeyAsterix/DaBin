DaBin 0.4.33 (88)

Main tabs: Projects → Tasks → Captions. The To organize shortcut is removed; use the Captions tab to return from Day/Week. Confirm selected date, filter and unfinished capture draft survive. More menus no longer offer Pin/Unpin.
Projects: create and choose named projects, All and Unfiled; use Back/Forward and reopen. Filters, selections, notes and drafts should return to the same scope. On a failed save, the current project remains selected and retry is available. Blocked navigation should not create unintended projects.
Projects: at narrow widths use the type menu, Any date, sort and Grid/List; recover empty results with Show all items. Select, copy mixed originals/notes, export the whole project or selected items, open details/originals and return. Reorder only in My order, with boundary actions disabled.
Projects: move items and use Undo move without navigating to All; a failed write should remain retryable. Convert captures to tasks and Undo immediately; editing a converted task/comment should protect that work and invalidate unsafe Undo. Clipboard/Shelf naming should retain a failed name with visible retry; deliberate Cancel resets it.
Project notes: edit across projects, return with Back, retry a failed save and confirm the text stays with its owning project. Trash/restore should keep related attachments together and always leave a usable return path.
Cards: title first, compact padding, aligned controls, content-sized text and useful saved-media previews. Original contents, dates, More, selection, drag/drop, planning, checklist, reminders, comments and attachments remain available.
Tasks: planned time explicitly says Today; Due is separate. Complete/reopen, start/pause/resume, minimize a timer, resize, edit the work plan and return from details. Retain unfinished drafts and Pause on minimized active tasks.
Settings → Quick access: configure, clear or reset Full screen and Recording shortcuts. Defaults: Control + Option + F and Control + Option + R. Check conflicts, holding a key, hide/reopen and recording while editing.

Delete: each saved content card exposes Trash or More > Delete. Test Projects/live notes, Search, Tasks, Captions, hourly groups, per-action groups, imported batches, task attachments and saved comments. Cancel should keep content. Delete/Undo/Recently Deleted Restore should recover exact items. A new capture arriving during group confirmation must survive; filtered hidden items and other tasks must remain. Restore deleted notes must refuse to overwrite newer saved or unfinished text. Permanent deletion affects only the removed copy and cannot be undone. Delete a saved comment while typing another: unfinished text, task plans and later replies must stay; Undo adds back only that comment.

File drags: export ordinary files/images and mixed batches to your working app. Check exact original contents and usable filenames. A prepared outgoing drag should remain readable after filing or deleting the saved capture. The DaBin stale-file URL bug is fixed; the reported OD_PROTOCOL_PROXY_FAILED receiving-app error itself has not been reproduced or confirmed. Include the receiving app and file type in any failure report.
