# DaBin 0.3.13

DaBin's two compact icon rows now align as one deliberate header system. The primary actions and filters each occupy the same **280 × 34-point** footprint, so their outer edges and vertical rhythm match in Daily and Weekly.

## What changed

- Standardized every icon on a **15-point SF Symbol** in an **18-point canvas**.
- Gave every control the same **40 × 34-point target** and **30-point circular** selected or hover surface.
- Distributed Add, Search, Export, Notifications and Settings between the same outer edges as the six filters.
- Preserved the existing control order, commands, popovers, tooltips and accessibility behavior.
- Kept both rows aligned in narrow Daily and Weekly layouts across light and dark appearances.

The exact optimized source passed all **30 registered Release suites with 2,706 checks**. Fresh native rendering produced **42 release interface views**, including empty and populated Daily plus narrow Weekly in light and dark appearances. The ARM64 build and update package passed clean-copy signature, extraction, fresh-install, replacement, backup and checksum verification. The public GitHub release and all four assets were verified without authentication. The installed 0.3.12 app then updated itself to 0.3.13 through Settings while preserving all 33 archive files, preferences and the Desktop link.
