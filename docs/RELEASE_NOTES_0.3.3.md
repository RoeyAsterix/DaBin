# DaBin 0.3.3

DaBin 0.3.3 makes Daily and Weekly feel like two views of the same board.

## What changed

- Replaced the separate **Today** and **This Week** actions with one compact **Daily / Weekly** control.
- **Weekly** opens seven days ending on the date already selected in Daily.
- Switching back to **Daily** keeps the selected date, type filter, scroll position and unfinished edits.
- Kept the centered date shortcut, weekly day headings, Back navigation, directional panel transition and Reduce Motion behavior.
- Updated the quick-start PDF to show the new control.

## Update

Open **DaBin → Settings → Software updates**, choose **Check for updates**, then **Download & install**. DaBin verifies the release size and SHA-256 checksum before its installer asks to replace the app. Captures and settings remain in the existing local archive.

The downloadable ZIP also includes the app, updater, release manifest, instructions and one-page PDF guide.
