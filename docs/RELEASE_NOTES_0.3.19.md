# DaBin 0.3.19 beta

This beta makes the DaBin robot feel at home in the Mac's camera island. The
robot peeks, climbs out, eats successful captures with varied reactions, and
expands into the Daily application frame. Opening and closing remain reversible,
Reduce Motion uses a calm fallback, and external displays use the top-right entry.

The beta also fixes macOS reopen behavior. Opening DaBin again now restores Daily
even when the floating window was occluded, transparent, or still marked visible
by AppKit.

All captures remain local. The Store build contains no GitHub updater or update
helper; TestFlight supplies beta updates.
